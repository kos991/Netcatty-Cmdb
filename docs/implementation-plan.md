## 本轮需求清单

### 必须保留

1. 终端资产、基础设施、业务系统三个独立子页与顶部跨类别搜索。
2. 三类资产、人员、地址池、工单和履历的条件查询、重置、分页；导出全部匹配，不受当前页限制。
3. 新增、编辑、批量操作、人员调换、维修换件、照片、凭证引用、履历和注销归档查回。
4. 资产、人员、组织、IPAM、承载主机、应用的实际详情穿透，不以关键词跳转代替关系。
5. 云桌面按类型名称识别，保留业务/虚拟机 IP、终端物理 IP 和双 SN；普通终端只设备 IP 与设备 SN。
6. 当前项目作用域、旧数据库自动迁移、明确错误、事务与旧数据保留。
7. 现有机柜位置迁移预览、备份、安全回滚、未分配设备批量指定机柜和未保存保护。
8. 现有工单附件本地/云存储、上传、下载、预览和真实状态流转。
9. Netcatty 原生 React、components/ui、Tailwind、Radix、Lucide 和宿主主题；不引入新的全局状态框架。

### 本轮新增或调整

1. 原型顶部：明确新增对象名称，业务范围和搜索集中；单一导入/导出图标，筛选保留。
2. 三类资产名称/编码/SN 摘要、IP 与网络类型分列、真实品牌与系统 Logo，未知值不冒充识别。
3. 统一 420px 右侧详情、图标页签、单内容区、编辑和展开/还原；新增居中表单。
4. 台式机、笔记本品牌/型号、CPU、内存 MB、磁盘贯通保存、详情、导入导出、旧资料映射和同步快照。
5. 终端每个有效 IP 后仅 22px 终端小图标；提示保留 Netcatty 和目标 IP，云桌面双 IP 各自可真实关联与连接。
6. 业务系统六页签：系统信息、网络配置、使用与归属、承载设备、运维履历、凭证中心。
7. 人员四页签：人员资料、组织归属、名下资产、资产交接；保留字段和备注、编辑、展开、键盘与真实事务。
8. 机柜左图右属性/照片；标题旁编辑 1–60U，高度数字与滑块联动，原位置保留，越界、重叠及缩小挤出拒绝。
9. 地址池保留类别分组、网格/列表、特殊地址、分页、查询、分配释放及导入导出。
10. 工单单排四阶段加独立弱化取消状态，列表为主；新增居中，详情 720px 紧凑单列，处理记录默认折叠，结单逐张必填结果。
11. 宿主 Cmdb 设置固定页头和五页签：资产目录、工单配置、导入模板、项目存储、同步维护；跨页签与宿主搜索定位，键盘与输入状态保留。
12. 分类层级稳定父 ID，新增大类/子类、搜索保留祖先、自身/后代排除；终端简称、目录、编号规则使用真实协议。
13. 单一 Cmdb 云同步总开关统一包含资产、组织及电话、IP、工单和履历；迁移旧设置、失败显式返回。
14. 旧台账迁入与云同步分开，明确范围、重复映射跳过、原数据保护和真实结果。
15. 项目名称/编码、附件目录/容量/可写状态和迁移使用真实当前项目及宿主数据。

### 明确移除

- 独立全局查询首页、Ant/MUI、web 正式入口等旧计划内容。
- 机柜上一柜/下一柜；重复标题/工具栏；文字 Netcatty 快连按钮。
- 电话/履历同步分项开关、重复同步状态行和立即同步。
- 工单详情的大流程图、重播、暂停等原型明确删除部分。
- 不删除业务数据、已有历史字段或本分支额外业务能力。

### 待确认

当前无阻塞产品选择；原型定义布局，真实行为复用当前分支协议。遇到会改变业务语义的分歧先核对，不擅自缩减。

## 根因、影响与回滚

根因：最新设计已进入原型，但正式组件及现有测试包仍是旧布局；此前错误地在 main 实施和启动，不能代表本分支。影响为本分支 `integrations/netcatty/`、必要的 `internal/` 字段/API、装配器和使用文档。采用现有迁移新增字段与既有事务，不物理删除资料。回滚边界为本轮文件改动和隔离测试副本，不重置用户改动或覆盖正式数据库。
