# 常州中院资产与服务器全景管理实现计划

## 目标

在保持现有 Go + SQLite、React + Ant Design 框架和既有业务流程的前提下，补齐独立全局查询、模块分页、资产联动、资产筛选导出和注销归档。

## 范围边界

- 保留现有资产新增、修改、调换使用人、维修换件、履历查看。
- 新增独立“全局查询”导航入口，作为默认首页。
- 资产、服务器、应用、履历、IP 池分别保留独立查询和分页。
- 资产详情展示人员、部门、房间、IP、服务器/应用和履历关联。
- 资产导出按当前筛选条件导出全部匹配记录。
- 删除改为注销归档，保留资产资料和履历，默认列表隐藏。

## 页面设计规矩（国产业务习惯 + 国际开源信息架构）

- 国产项目（蓝鲸 CMDB、JumpServer）只借鉴内网运维场景中的分类树、业务分组、高密度字段和审计习惯，不照搬产品页面。
- 国际开源项目（NetBox、Snipe-IT、GLPI）只借鉴成熟对象模型、独立台账、IP 占用可视化、生命周期和详情穿透，不引入其重量级扩展。
- 每个模块必须根据业务对象采用自己的页面骨架：服务器使用“机房树 + 台账/机架概览”，云桌面使用“状态与人机流转”，IP 池使用“网段利用率 + 地址矩阵”，履历使用“时间流水”。
- 全局查询是统一入口，但不能替代任何模块台账；模块内查询、分页、详情和操作必须独立存在。
- 本轮按一个页面一个页面实施。先改页面形态，再补充该页面所需的接口；不同时重做所有模块，不增加关系图、复杂路由或新的前端状态框架。
- 不新增关系表、人员表、FTS、ORM、缓存、拓扑图、异步导出或复杂路由。

## 实施步骤

### 1. 后端查询基础

文件：`internal/store/store.go`

- 统一分页参数的生效值，保证响应中的 `page/page_size` 与实际查询一致。
- 补齐应用和 IP 池的分页查询，返回 `list/total/page/page_size`。
- 保持现有资产、服务器、履历查询字段和筛选条件。
- 默认查询排除已注销资产；增加 `include_archived` 查询开关。

### 2. 全局搜索接口

文件：`internal/store/store.go`、`internal/server.go`

- 新增 `GET /api/search?q=&limit=`。
- 对资产、服务器、应用、履历、IP 池分别执行参数化模糊查询。
- 返回分组结果，每条结果包含类型、ID、标题、摘要和必要的原始字段。
- 空关键词返回空结果，不查询全表。

### 3. 资产关联接口

文件：`internal/store/store.go`、`internal/server.go`

- 新增 `GET /api/assets/{id}/relations`。
- 通过现有字段查询：资产 IP 对应 IP 池和服务器地址，服务器通过 `server_id` 取得应用，资产取得人员位置和履历。
- 关联结果无法确定时返回空列表或“未关联”，不伪造关系。

### 4. 资产注销与导出

文件：`internal/store/store.go`、`internal/server.go`

- 将现有删除行为改为事务式注销：更新状态为“已报废”，写入“设备回收注销”履历。
- 已注销资产再次操作时返回明确错误。
- 导出接口接收资产列表相同筛选参数，查询全部匹配记录后生成 Excel。
- 保留现有新增、修改接口和维修/调换流程。

### 5. 前端导航与 API

文件：`web/src/App.jsx`、`web/src/api.js`、`web/src/GlobalSearch.jsx`

- 左侧增加“全局查询”，默认打开该页面。
- 接入 `api.search` 和资产关联接口。
- 全局搜索结果按五类分组，点击结果切换到对应模块并打开已有详情入口或列表定位。
- 不引入新的状态管理库和复杂路由。

### 6. 前端模块分页与资产联动

文件：`web/src/AssetCenter.jsx`、`web/src/ServerCenter.jsx`、`web/src/IPManager.jsx`、`web/src/AuditLogs.jsx`

- 应用、IP 池和已有列表统一使用服务端分页。
- 资产详情抽屉增加关联信息区域。
- 资产操作区保留新增、修改、导出、注销、调换、维修和履历。
- 注销使用二次确认和原因输入；导出按钮明确表示导出当前筛选的全部数据。

## 验证

- 后端：`go test ./...`。
- 前端：在 `web/` 执行 `npm run build`。
- 手测：默认进入全局查询；五类结果可查；模块可分页；资产详情显示关联；新增、修改、注销、导出可用；注销记录默认隐藏且可筛选查回。

## 不做事项

- 不改变现有页面框架为关系图或多级路由。
- 不重构数据库为统一资产主表或新增复杂归档快照。
- 不把资产联动简化成仅按关键词跳转。
