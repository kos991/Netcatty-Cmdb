# Netcatty Cmdb UI 问题台账

## 使用规则

- 本台账记录五个模块在界面、交互和职责边界上的已确认问题。
- “已定方案”表示产品方向已经确认，不代表代码已经实现。
- 每项关闭前必须有自动化验证或 Netcatty 隔离测试机中的实际界面证据。
- 本台账不授权提交、推送、发布、修改版本号或修改正式 Netcatty 安装目录。

## 基础设施筛选专项验收规则

1. 筛选栏只保留真实业务维度，不展示 `source_type` 等内部存储来源。
2. 设备类型必须能筛选当前列表中实际出现的服务器、虚拟机、交换机、路由器、安全设备、存储、超融合和云桌面相关基础设施，不能只展示与数据脱节的四个旧选项。
3. 资产状态和运行 / 连接状态分开；没有实时采集依据时不显示运行 / 连接状态筛选。
4. 资产分组必须支持“未分组”，组织必须支持“未归属”。
5. 操作系统与版本只对适用的计算类设备生效；选择系统类型后，版本选项只显示该系统的实际版本。
6. 排序不计入“更多筛选”数量；“更多筛选”的计数必须与真正生效的条件一致。
7. 列表、分页、导出和重置必须使用完全相同的筛选条件，并始终限定当前项目。

## 终端资产筛选补充验收规则

1. “资产分组”同时提供全部、未分组和当前项目的有效分组。
2. 选择“未分组”后只返回 `group_id` 为空或为零的终端资产，不能继续返回全部终端资产。
3. 当前列表筛选、分页总数和导出结果必须一致。

## 已确认的模块边界

1. 设备资产负责终端资产、基础设施、业务系统，以及分类、分组和各资产的录入规则。
2. 组织架构负责组织节点、人员、人员拖拽和责任资源归属。
3. IPAM/IP 负责网段、IP、VLAN、VXLAN 和地址占用关系。
4. 工单与统计负责新建工单、当日工单、统计筛选、附件和导出。
5. 配置中心只负责工单配置和项目设置，不再负责资产配置。
