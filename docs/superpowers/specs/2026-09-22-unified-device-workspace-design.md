# 基础设施统一设备工作区设计

## 目标

将交换机、路由器、服务器当前分裂的详情界面收敛为 Netcatty 原生的统一设备工作区。统一页面骨架、资产归属、生命周期操作和关联能力，同时按设备类型展示真实存在的专属运维内容，不伪造尚未实现的采集能力。

## 当前问题

1. 交换机使用半屏工作区，路由器和服务器仍使用窄详情抽屉，操作位置和信息层级不一致。
2. 交换机遗漏项目、组织、分组、负责人和物理位置等资产归属。
3. Netcatty 主机关联入口被埋在深层栏目，读取配置的前置条件不清楚。
4. ACL、账号、SSH/Telnet、SNMP 被拆为多个同级页面，安全排查需要频繁切换。
5. 端口快照可能包含 `allowedVlans: {}`，点击端口时调用 `.join()` 会导致页面崩溃。
6. 固定最小宽度和宽表会在较小窗口内产生双重横向滚动。

## 设计决策

采用“共享工作区骨架 + 设备类型专属模块”，不复制三套详情页面。

### 固定标题栏

- 返回基础设施列表。
- 设备类型图标、名称、资产编码和运行状态。
- 设备主操作：交换机显示“读取配置”；路由器和服务器显示 Netcatty 连接入口。
- 半屏/最大化切换。
- 编辑、克隆和注销归档。

### 固定资产归属条

按现有真实字段展示：

- 所属项目：使用当前项目上下文中的项目名称；无法取得名称时显示项目编号，不伪造名称。
- 组织、部门和分组：`org_name`、`department`、`group_name`。
- 负责人：`owner`。
- 物理位置：`room`、`data_center`、`floor`、`cabinet_name`、`start_u`、`height_u`。
- 快速定位：管理 IP 和设备 SN。

缺失值显示“未分配”或“-”，让运维人员能识别台账缺口。

### 公共区域

三类设备共享以下能力：

- 网络接口和 IPAM/IP 关联。
- 上下联链路查看、添加、删除和对端设备穿透。
- Netcatty 主机与钥匙串关联管理。
- Netcatty 原生连接入口；关联管理与发起连接使用不同按钮和文案。
- 变更履历。
- 资产档案。

### 设备专属区域

#### 交换机

- 设备配置摘要：厂商型号、系统版本、设备名称、管理地址、读取协议、管理 VLAN、聚合组、接口统计和最后读取时间。
- 端口面板常驻主视图，点击端口就地显示状态、作用、PVID、允许 VLAN、聚合组和对端状态。
- 端口详情提供“添加链路”，自动带入端口号。
- “安全与访问”作为一个可展开区域，内部保留 ACL、设备账号、SSH/Telnet 和 SNMP。
- 只读配置继续使用 Netcatty 原生 SSH/Telnet 连接和现有快照接口。

#### 路由器

- 展示现有资产字段、网络接口、管理 IP、网关、网络区域、IPAM 和上下联链路。
- 提供 Netcatty 主机/钥匙串管理和原生连接。
- 不展示路由表、NAT、VPN 或配置备份等当前不存在的采集结果。

#### 服务器与虚拟机

- 承载业务系统作为默认主视图，支持穿透到业务系统详情。
- 展示现有 CPU/vCPU、内存、磁盘、型号、操作系统、业务 IP、管理 IP 和带外管理地址。
- 展示网络接口、IPAM、上下联链路、Netcatty 连接和变更履历。
- 系统识别沿用现有 Netcatty 连接流程，不新建另一套连接机制。

## 展开规则

- 默认半屏，左侧资产列表保留。
- 标题栏和资产归属条常驻。
- 设备专属主视图默认展开。
- “网络与关联”“Netcatty 连接”“档案与履历”按需展开。
- 交换机“安全与访问”默认收起，展开一次即可查看四类安全信息。
- 最大化时覆盖内容区，不丢失当前设备、选中端口和展开状态。
- 切换到另一台设备时保留半屏/最大化偏好，但重置选中端口和设备专属临时状态。
- 从链路打开对端设备时沿用当前工作区宽度，并加载对端设备的默认主视图。

## 错误与数据边界

- 在纯数据层归一化快照数组、端口状态和空值；组件不直接信任后端快照形状。
- `allowedVlans` 支持数组和字符串，其他类型归一化为空数组。
- 无快照、无关联主机、读取失败、空接口和空链路分别显示可操作的空状态。
- 设备工作区设置局部错误边界，单个专属面板失败时不卸载整个 Cmdb 页面。
- 不吞掉读取或关联错误，错误信息保留在当前工作区中。

## 响应式边界

- 半屏目标宽度约为内容区 50%，不使用会把面板撑出视口的固定宽表。
- 低于可读宽度时允许面板占比提高，但页面本身不得出现双重横向滚动。
- 表格在半屏使用紧凑列和局部横向滚动；最大化后再展示完整列。
- 端口格使用自适应网格，不因状态、标签或端口号改变尺寸。

## 不做事项

- 不新增路由表、NAT、VPN、SNMP 写入或交换机配置修改能力。
- 不修改现有后端数据模型，除非实施时发现项目名称无法从现有上下文取得。
- 不引入新的前端框架、全局状态管理或关系图。
- 不发布、不修改正式 Netcatty 安装目录、不变更版本号。

## 验收标准

1. 三类设备使用相同标题栏、资产归属条、宽度切换和生命周期操作位置。
2. 三类设备现有公共能力完整保留。
3. 点击包含 `allowedVlans: {}` 的端口不会产生运行时异常。
4. 交换机读取配置、端口、安全配置和链路履历均不超过一次栏目切换。
5. 路由器不出现虚假的路由表、NAT 或 VPN 数据。
6. 服务器承载业务、硬件系统、网络和 Netcatty 能力均可到达。
7. 1366x768 与当前桌面窗口下无页面级横向溢出。
8. 半屏/最大化切换以及对端设备穿透不会丢失列表筛选和页码。
