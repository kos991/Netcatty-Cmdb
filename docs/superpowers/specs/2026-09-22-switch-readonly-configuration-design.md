# 交换机只读配置集成设计

## 1. 目标与范围

在 Netcatty 内嵌 Cmdb 的“设备资产 > 基础设施 > 交换机详情”中，复用该资产已关联的 Netcatty 主机，通过主机实际配置的 SSH 或 Telnet 连接读取交换机配置，并展示最近一次成功读取的标准化快照。

本期只读取和展示，不向交换机下发配置，不进行 SNMP 轮询，不采集实时带宽，不保存完整命令输出，也不保存多版本历史。

支持范围：

- 设备配置：厂商、型号、设备名称、系统版本、管理地址、管理 VLAN、聚合组、接口统计。
- 端口配置：接口名称、启停状态、接口描述、Access/Trunk、VLAN、允许 VLAN、聚合关系。
- 接口作用：沿用 Cmdb 手工维护的上联/下联、对端资产、对端接口、用途和备注。
- 安全与访问配置：ACL 规则、设备账号、SSH/Telnet 服务、SNMP 配置。
- 厂商适配：华为、H3C、锐捷、思科、中兴；未知厂商返回“暂未适配”，不伪造解析结果。

## 2. 明确排除

- 不读取或展示实时入/出带宽，不显示趋势图，不做定时流量采样。
- 不要求设备同时启用 SSH、Telnet 和 SNMP。读取入口只使用资产关联主机已经配置的 SSH 或 Telnet 协议。
- 不通过 SNMP 查询设备；页面中的“SNMP 配置”是通过 CLI 只读命令识别出的配置摘要。
- 不保存 running-config、current-configuration 等完整原文。
- 不读取、还原、展示或保存密码、密码哈希、密码密文、SNMP Community、SNMPv3 认证密钥或加密密钥。
- 不自动创建拓扑关系，不使用解析结果覆盖 Cmdb 手工维护的接口作用。
- 不执行配置模式命令、保存配置命令、启停服务命令或接口变更命令。

## 3. 职责边界

### 3.1 Netcatty

- Vault 继续管理主机、身份和密钥，Cmdb 不复制任何秘密值。
- 读取配置前按 Cmdb 中的主机引用解析真实 Netcatty 主机。
- 使用该主机的协议、地址、端口和身份建立 SSH 或 Telnet 会话。
- Electron 主进程提供受限的“交换机只读命令执行”能力，渲染层不能提交任意命令。
- 每个厂商适配器只能调用代码内固定的只读命令集合。

### 3.2 厂商适配器

- 第一阶段通过只读识别命令确定厂商和系统版本，再选择华为、H3C、锐捷、思科或中兴适配器。
- 适配器负责命令编排、分页关闭、输出编码处理和标准化解析。
- 各厂商输出统一转换为交换机快照结构；字段无法确认时返回空值和解析警告，不猜测。
- 命令输出仅在读取过程内存中存在，完成解析或失败后释放，不写日志和磁盘。

### 3.3 Cmdb Go 服务

- 校验目标资产属于当前项目且设备类型为交换机。
- 保存最近一次成功的脱敏标准化快照、读取时间、读取协议、适配器名称和解析警告。
- 保留现有接口作用与上下联关系，按规范化接口名称与快照接口合并展示。
- 读取失败不覆盖成功快照，只记录本次可展示的失败结果，不保存原始输出。

### 3.4 React 界面

- 只在交换机详情中展示“读取配置”入口。
- 未关联 Netcatty 主机时，提示先关联主机；不显示虚假的读取成功状态。
- 有成功快照时优先展示快照，并显示最后读取时间、协议和适配器。
- 端口悬浮展示接口名称、启停、模式、VLAN和接口作用；不重复显示端口展开区和接口明细表。

## 4. 数据流

1. 用户打开交换机详情，Cmdb 返回资产、Netcatty 主机引用、手工链路和最近成功快照。
2. 用户点击“读取配置”。
3. 渲染层根据主机引用从 Netcatty Vault 解析主机和凭据，并请求受限 Electron IPC。
4. Electron 验证目标是允许的主机引用，并根据主机协议建立 SSH 或 Telnet 会话。
5. 识别器执行固定只读命令，确定厂商；对应适配器继续执行固定命令并解析输出。
6. Electron 返回标准化、已脱敏的结果，不返回凭据和完整命令输出。
7. 渲染层将标准化快照提交给当前项目的 Cmdb 接口。
8. Go 服务再次执行敏感字段校验，原子替换该资产的最近成功快照。
9. 前端按规范化接口名称把快照接口与 Cmdb 手工链路合并后展示。

读取失败时，第 8 步不更新快照；界面显示明确错误并继续展示上次成功快照。

## 5. 快照数据结构

采用每个项目、每个交换机一条“最近成功快照”，JSON 内容带 `schema_version`，避免为只读详情引入大量查询表。

快照元数据：

- `project_id`
- `asset_id`
- `host_id`
- `protocol`
- `adapter`
- `captured_at`
- `schema_version`
- `warnings`

标准化内容：

- `device`：厂商、型号、名称、系统版本、管理 VLAN、聚合组。
- `interfaces`：规范化名称、原始名称、描述、管理状态、链路状态、模式、VLAN、允许 VLAN、聚合组、物理/逻辑类型。
- `acls`：名称/编号、类型、规则摘要、动作、应用位置。
- `accounts`：用户名、角色/等级、允许服务、认证方式、启用状态、密码配置状态。
- `management_services`：SSH/Telnet 的启用状态、端口、版本、认证方式、源接口和绑定 ACL。
- `snmp`：启用版本、用户/组名称、安全级别、认证/加密算法名称、视图、ACL和 Trap 目标。

快照禁止出现名称包含 `password`、`secret`、`community_value`、`auth_key`、`priv_key`、`hash`、`ciphertext` 的字段。所有秘密统一转换成 `configured: true/false` 或“已配置（隐藏）”。

## 6. 接口名称匹配

- 先保留厂商返回的完整接口名，再生成规范化名称用于匹配。
- 规范化处理大小写、空白和常见缩写，如 `GigabitEthernet` 与 `GE`、`XGigabitEthernet` 与 `XGE`。
- `ifIndex` 不作为正式关联键，防止设备重启、堆叠变化后索引漂移。
- 只有唯一匹配时才合并 Cmdb 接口作用；多义或无法匹配时保持未登记，并给出解析警告。
- 自动读取结果与手工关系并列展示，永不自动修改对端资产关系。

## 7. 页面布局与适配

交换机详情保持 Netcatty 原生抽屉和紧凑信息密度：

1. 标题区：资产名称、管理 IP、关联状态、编辑资产、读取配置。
2. 快照状态：最后成功时间、连接协议、厂商适配器；失败时同时显示错误和旧快照时间。
3. 设备配置：四列紧凑定义列表；窄窗口降为两列。
4. 端口面板：桌面默认十二列，中等窗口十列，小窗口六列；端口格固定尺寸，不随文字变化。
5. 安全与访问配置：`ACL规则`、`设备账号`、`SSH/Telnet`、`SNMP配置` 四个页签。

已确认删除：

- 选中端口后的大块“设备识别配置 / CMDB 接口作用”区域。
- 重复的“接口明细”表格。
- 带宽数值和趋势图。

## 8. 错误与安全处理

- 未关联主机、Vault 锁定、凭据失效、连接超时、权限不足、命令不支持、厂商未知和解析失败必须分别返回明确错误。
- 单次读取设置总超时；用户关闭详情或再次读取时可取消正在运行的任务。
- 同一交换机同一时刻只允许一个读取任务，重复点击复用进行中状态。
- CLI 输出和凭据不得进入应用日志、Cmdb HTTP 日志、SQLite或错误详情。
- Go 服务在持久化前递归检查禁止字段；发现敏感字段时拒绝整个快照，不以部分成功掩盖问题。
- Telnet 连接在界面明确标识“未加密连接”，但不阻止用户读取已有设备。

## 9. 测试与验收

### 自动测试

- 厂商识别和五类适配器解析使用脱敏固定样本测试。
- 验证所有命令均来自白名单，渲染层不能提交任意命令。
- 验证敏感字段和疑似秘密值无法进入快照。
- 验证读取失败保留旧快照，成功读取原子替换旧快照。
- 验证接口名称规范化、唯一匹配和冲突不匹配。
- 验证项目隔离和非交换机资产拒绝保存交换机快照。
- 验证页面页签、端口悬浮、读取状态、错误状态和响应式断点。

### 本地测试版验收

- 只加载到隔离的 Netcatty 测试目录，不修改正式安装目录。
- 使用 SSH 和 Telnet 各验证一台可控测试设备；没有真实设备时只验证录制样本和失败状态，不声称完成真实连接验证。
- 分别检查华为、H3C、锐捷、思科、中兴样本的设备、端口、ACL、账号、SSH/Telnet和SNMP摘要。
- 检查密码、哈希、密文、Community和SNMPv3密钥未出现在界面、日志、接口响应和数据库中。
- 检查 1366×768、1920×1080 和较窄窗口下无溢出、遮挡或超大控件。

## 10. 保留的既有能力

- 基础设施 CRUD、分页、导入导出、归档和项目隔离保持不变。
- 交换机上下联、VLAN/VXLAN、IPAM 与 Netcatty 主机关联保持不变。
- 关联主机后的 Netcatty 原生连接入口保持不变。
- 先前确认的双 IP 直连和系统识别回写需求继续保留，但不与本交换机快照耦合，分别沿用其独立调用链实现和验证。

## 11. 回滚边界

- 新增的交换机快照表和读取 IPC 均为增量能力。
- 禁用或移除读取入口后，现有资产、链路、主机关联和其他 Cmdb 页面不受影响。
- 数据库迁移只新增表或字段，不改写既有资产和链路数据。
