# 工单配置中心原型实施计划

> **执行要求：** 使用 `executing-plans` 按任务逐项实施，并使用复选框（`- [ ]`）跟踪状态。

**目标：** 构建一版可交互的 Netcatty 原生配置中心原型，用于确认工单编号规则、类别模板、运维类型和优先级配置。

**架构：** 以已确认的工单 v13 原型为视觉基线，新建独立的配置中心 HTML 原型，不修改正式 React、Go 或 SQLite 代码。原型使用内存状态模拟配置保存，并提供进入新建工单预览的联动入口。

**技术栈：** 单文件 HTML、CSS、原生 JavaScript、Brainstorm Visual Companion、Playwright。

### 任务 2：制作工单编号规则页

**文件：**
- 修改：`.superpowers/brainstorm/11-1789779172/content/work-order-config-center-v14.html`

- [x] **步骤 1：添加受控规则字段**

字段包括固定前缀、分隔符、日期段、流水号位数和重置周期；默认值生成示例 `GD-20260920-0001`。

- [x] **步骤 2：添加实时预览**

每次修改选项后立即刷新示例编号，并显示“仅影响后续新工单，历史编号不变”。

- [x] **步骤 3：添加保存反馈和非法值提示**

前缀只接受 1-12 位大写字母或数字；无效时显示字段错误且禁止保存。保存只更新原型内存状态并显示成功提示。

- [x] **步骤 4：验证编号交互**

Playwright 修改所有规则项，断言预览值同步变化；输入非法前缀时断言保存按钮禁用或显示错误。

**文件：**
