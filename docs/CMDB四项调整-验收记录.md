## 6. 已知限制

1. **分组 / 类型仍为 0 条**（用户明确选择不预置）：因此「设备分类」列仍显示 `-`、仪表盘「设备分类分布」仍只有「未分类」。需要你在「分类管理」里自行新增，并给资产逐个或批量指定分类。

3. **旧「统一资源管理」的保留分支仍在包内**：`App.jsx` 保留了 `currentMenu === 'cmdb'` 的渲染分支与 63KB 组件，用于随时恢复；如需彻底移除以减小包体，需另行确认。
4. **两个业务模块嵌入后仍带自己的页内标题**：`AssetCenter` / `ServerCenter` 原为整页设计，嵌入 CMDB 后可能出现「页面标题 + 模块内标题」重复的情况（未实测）。
