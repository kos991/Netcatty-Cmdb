# Cmdb 交互设计原型

本目录是当前设计评审的完整离线 HTML 原型，包含页面、示例数据、样式、脚本、Logo 和动画依赖；不是正式客户端，也不连接 Go 服务、SQLite、凭证或真实资产。原型已从 `.prototype/` 整体移入本目录，不再维护两份源码。

**当前状态：统一详情／新增／编辑外壳正在本目录进行设计预览，尚未迁入正式客户端。** 本轮修改只影响离线原型；正式行为与验证记录见项目[验收清单](../../acceptance-checklist.md)，不能把本目录的草稿或模拟采集结果当作真实业务保存。

## 本轮设计约定

- 本轮六项界面修正已同步正式源码与原型：①资产/人员侧栏“放大/还原”只切换全宽，“左右分栏”（`columns-2`）独立切换正文单/双列，二者互不共用状态，保留 420px 默认与拖宽；②CPU、内存、磁盘编辑区顶部提供可应用、存为常用、删除的“常用”预设（仅本机），420px 窄栏下按字段宽度折行，无法拆分的原文不被预设覆盖；③三类资产首列表头用不截断短名（“名称 / 编码 / SN”“名称 / 编码”“系统名称”），悬停显示完整名称；④三类资产行操作统一为一个紧凑“操作 ▾”分组菜单，保留查看、编辑、克隆、调换、维修、注销全部适用操作；⑤设置 Cmdb 标题旁为版本标签（正式客户端显示真实发布 tag，未打 tag 显示“开发构建”，原型显示“版本未读取”）与“检查更新”，原型不联网、不编造版本；⑥网络类型目录左侧显示已保存颜色圆点，原型可保存到本页内存并同步列表色点，刷新恢复示例。

- 顶部明确显示新增对象名称，类别、机房/机柜、人员状态等选择集中在顶部，不重复增加页面标题栏。左侧只保留“机柜与网络”一级图标，使用 Lucide `Router`，与二级导航的“机柜”`Server`、“网络”`Network` 区分，不重复同一图标；点击直接进入机柜页面。内容区工具栏最左侧提供“小图标＋文字”的横向“机柜／网络”二级导航，以蓝色下划线标识当前页面。两个独立HTML页面保留，不再在54px窄侧栏堆叠图标和文字。
- 设备资产三类页面、人员、地址池和工单均只使用一个 `ArrowDownUp` 导入/导出图标，点击后显示菜单；菜单内使用 `Upload` / `Download` 图标。没有数据交换操作的机柜视图不增加虚构导入导出功能。
- 终端、基础设施、业务系统、组织、工单和地址池的顶部新增入口统一使用现有 `primary` 主按钮样式；组织维护的新增节点、IPAM 补录 IP、机柜管理的新建机房/机柜及空 U 位新增设备同样复用该样式。仅显式新增主按钮采用主色，菜单内项目、查询、编辑及原表单行为保留。
- 查询、编辑、关闭、详情页签、导航等共享 [Netcatty 同版本 Lucide 图标数据](vendor/netcatty-icons.js)，不是手绘近似路径。
- 基础设施品牌/型号前显示对应品牌 Logo；终端操作系统前显示 UOS、麒麟、Windows 等实际 Logo。未知、不适用或未配置不冒充已识别品牌；文字仍保留一次。
- 台式机、笔记本的“硬件信息”包含品牌/厂商、型号、CPU、内存（MB）和磁盘；打印机同样显示品牌与型号，复用列表、详情、新增和编辑字段，但不显示 CPU、内存或磁盘。示例打印机填充奔图 PANTUM P2500、联想 LJ2205；品牌可选奔图、立思辰、联想、得力、映美等，也可自定义，候选合并既有型号目录和资产品牌。缺少真实 Logo 的品牌只显示文字，不伪造标志；品牌与型号示例不代表信创认证。
- 三类资产列表及网络详情在已填写 IP 后只显示一个 22px 原生终端小图标，不显示 Netcatty 文字；悬停提示和无障碍名称保留 Netcatty 与目标 IP。终端设备 IP、云桌面业务/物理 IP、基础设施管理/业务 IP、业务系统自身业务 IP 均分别提供入口，基础设施列表在同一地址单元格中区分管理与业务两行，无 IP 不显示图标；长地址在列表截断并保留完整悬停值。离线原型点击只在地址旁提示“请在 Netcatty 客户端中打开该地址的连接”，不新建弹窗、不模拟终端、不显示虚构服务器状态，也不猜测外部唤起协议。
- 业务系统列表在业务IP之前单独显示“访问地址”，直接读取已有access_url，保留完整协议、端口、路径及查询参数；长值换行、可选择文本，不以IP拼造，不创建真实访问链接。有效 http/https 地址旁新增 Netcatty 浏览器小图标（globe），点击提示需在 Netcatty 客户端打开该访问地址（须已关联主机），不弹出模拟浏览器或虚构页面；未配置独立显示，原业务IP不删除。
- 三类资产与人员详情、编辑共用统一外壳：顶部三条栏固定。第一条左侧为对象图标、名称、状态和辅助信息；资产详情与编辑右侧统一保留放大/还原（只切换全宽）、左右分栏（`columns-2`，只切换正文单/双列，与全宽独立并记住选择）、关闭三个窗口控件，人员详情与编辑同样保留展开/还原、左右分栏、关闭（人员详情另含编辑与更多操作），反复开关不重复堆叠，不再放置对角展开和右栏分栏的重复入口。第二条为当前对象适用的业务操作图标（资产：编辑、调换使用人、维修换件、克隆、注销；人员：编辑、删除入口），履历仍在详情页签中；第三条为详情/表单图标页签。页签在侧栏约 420px 时为纯图标，拖宽超过约 600px 自动显示图标+短文字（如“硬件信息”“人员资料”），恢复窄宽自动收回。面板配色对照原生右栏：浅色为灰蓝底 `#f6f8fb`、信息块为白色圆角卡片，暗色跟随主题变量（面板 `--surface`、正文 `--bg`），不写死浅色。资产侧栏左边界可拖动调宽（360–720px），列表同步让位；双击恢复 420px，展开再还原保持调节宽度。编辑复用同一外壳并共享宽度；草稿关闭确认、人员“返回详情”逻辑不变。新增仍为860px居中表单。
- 工单概览保持单排：新建 → 处理中 → 已解决 → 已关闭；已取消是同排独立的弱化状态，不接在“已关闭”之后的成功路线上。阶段数量和点击筛选保留，主列表获得更多高度。
- 人员详情统一420px右栏，人员资料、组织归属、名下资产、资产交接四个图标页签（名称在悬停提示中，与原生一致）；人员编辑同样只显示“人员资料／组织归属”两个图标页签。编辑采用同一右栏、新增采用860px居中表单，人员资料与组织归属分区共享输入。八个原有字段、备注、接收人选择保留，切换分区及展开还原不丢草稿；删除收进更多菜单，真实保存、删除和交接仍禁用。
- 工单详情改为紧凑 720px 居中单列，去掉大流程图、重播和暂停。主题、状态、基本信息和关联资料直接展示；处理结果、时间线及添加记录收进默认折叠的“处理记录”。保留下一步和取消操作，结单仍逐张要求处理结果；列表单排概览及动画不变。
- 所有当前业务页面均可从右上角设置图标进入同一个 Cmdb 设置原型。排版对照 Netcatty 的 `SettingsPage`、`SettingCard`、`SettingRow` 和 `Tabs`：保留宿主设置导航，Cmdb 内容改为固定页头与五个分区页签——资产目录、工单配置、导入模板、项目存储、同步维护。八个原有配置区完整保留，每次只展示当前页签；14px 设置名称、12px 说明、36px 输入控件，说明过长时可悬停查看全文，不再纵向堆成长页面。
- Cmdb 设置搜索覆盖全部分区，选择结果自动切换对应页签并定位；支持匹配结果、方向键/回车和空结果，Esc 只收起搜索。页签支持方向键、Home/End；切换保留项目输入、开关状态和各区滚动位置。项目名称、项目编码、附件目录/容量和同步结果均不伪造；目录为明确的结构样例，不能当作实际项目配置。
- 云同步只保留一个“同步 Cmdb 数据”总开关，设计范围明确包含资产、组织及联系电话、IP、工单和履历；移除电话/履历分项开关、同步状态行和“立即同步”按钮，云同步的执行与状态由宿主统一管理。“同步历史台账”改为“旧台账迁入”，提供“查看迁入预览”，保留当前项目范围、已有映射跳过和原数据保护约定。这是原型设计调整，正式同步行为未改动。
- 三类资产列表与原生一致，在名称后显示 8px 网络类型色点，颜色读取“设置 → Cmdb → 网络与型号 → 网络类型”的颜色（示例：专网 `#2563EB`、外网 `#F59E0B`、内网 `#10B981`），未配置或目录未设色时使用中性灰；首列表头与原生一致为不截断短名并悬停显示完整名称：终端“名称 / 编码 / SN”（设备名称 / 资产编号 / 设备SN）、基础设施“名称 / 编码”（设备名称 / 资产编号）、业务系统“系统名称”。网络类型目录提供颜色选择器和 `#RRGGBB` 输入，左侧目录显示已保存颜色圆点，与原生 `ConfigCenter` / `SettingsCatalogEditor` 一致。
- 三类资产分类使用固定 ID 与父 ID 的树目录，支持新增大类/子类、搜索保留祖先、选择回填；上级不可选自己或后代，终端分类保留设备简称。网络类型、型号及工单目录按实际字段使用列表表单。编号规则沿用 `YYYYMMDD / YYYYMM / YYYY / NONE` 等实际协议，而不是将示例日期写入协议值。除网络类型可保存到本页内存（刷新恢复示例）外，真实保存、下载、迁移和同步仍禁用。
- 机房、机柜下拉只负责选择；“管理机房 / 机柜”独立提供新建机房、新建空机柜、编辑选中机柜。总 U 数以数字和滑块联动（1–60U），不是设备高度；缩柜不得挤出已有设备。同名机柜按机房隔离。空 U 数字和空槽均可打开“新增设备 / 上架已有设备”，保存草稿前不改变占用；越界和重叠明确报错。保存、下架及照片示意状态仅存在本页内存，刷新恢复样例。
- 机柜页按“紧凑机柜图／设备属性与照片／机房机柜管理”三栏同时显示；管理常驻最右侧，不隐藏或替换设备属性，不再提供顶部管理按钮和返回设备属性按钮。管理区目录在上、表单在下，独立滚动。标题总U数可聚焦右栏当前柜；同柜选择设备不清空管理表单草稿。
- 机柜图最大400px，不随窗口拉宽。1240px以下管理区移到柜图与属性下方，720px以下单列顺排，所有区域始终存在，不切换。流光、上／下架、照片和校验保留。
- 硬件录入由[共享组合控件](asset-hardware-controls-preview.js)负责：CPU数量＋可自定义型号＋说明；磁盘数量＋任意容量＋MB／GB／TB／PB＋介质接口＋阵列说明。SATA、SSD、U.2、SAS、NVMe等为可选建议，不限制自定义；内存按1024换算到原memory_mb，vCPU直接填写整数。新增／编辑、台式机／笔记本、服务器／存储／虚拟机使用同一控件。
- 组合输入实时同步原字段，也保留完整配置文本编辑。无法可靠拆分的旧原文不自动替换；需明确点击“用分项替换完整文本”。切换类型保留草稿，SSH模拟仅回填勾选原字段，之后可继续组合修改。
- 默认仅展示常用输入：CPU数量与型号同排、内存数值与单位同排、磁盘数量／容量／单位一排及介质一排。说明、完整配置与原始MB值放入可展开区；已有说明以“已填写”标识，未知旧原文默认展开防止被隐藏。折叠不影响原字段同步或内容保留。

## 保留的原型交互与边界

- 保留三类资产切换、跨类别搜索、条件筛选、分页、详情、表单、调换/维修/归档流程预览；这些表单不会修改业务数据。
- 保留组织树、人员状态筛选和分页、人员详情、新增及组织维护表单预览。
- 保留地址池选择、方格/列表、状态查询、分页、IP 详情、新增/编辑地址池及机柜切换。地址池维护为居中双栏弹窗：左侧搜索并选择任意地址池，右侧编辑名称、网络类型、CIDR、网关、VLAN/VNI、用途与排序；入口为地址池下拉底部的“编辑当前地址池”和“新增地址池 → 维护其他地址池”，工具栏不再重复放编辑按钮。IP 分配等业务动作仍禁用。
- 工单新增、编辑和状态流转仅影响当前页面内存；刷新恢复示例数据。文件导入导出、真实附件上传和业务删除仍禁用。
