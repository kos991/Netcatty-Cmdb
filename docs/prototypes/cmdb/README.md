# Cmdb 交互设计原型

本目录是持续完善中的离线 HTML 设计原型，包含页面、示例数据、样式、脚本与资源；不是完整定稿，也不是正式客户端，不连接真实业务数据。原型已从 `.prototype/` 移入本目录，不维护两份源码。

**当前状态：用户明确指出原型仍不够完善。历史局部浏览器验证不代表全部页面、状态或设计已经通过验收。** 网页设计与补齐要求见 [项目执行与验收规则](../../project-execution-contract.md#网页原型设计与补齐契约)。先区分已确认设计、待完善交互、已否定方案，再进行原型修改或GPUI迁移，不将模拟保存当作真实持久化。

## 图标规范（已统一 Lucide）

原型与 GPUI 桌面中所有可替换的通用操作、状态与导航图标统一采用官方 [Lucide](https://lucide.dev/) 0.560.0 规范节点，废除所有交互字符字形（如 `⌄`、`▾`、`▴`、`▸`、`📌`、`⚡`、`▧`、`▱`、`□`、`×`、`+`、`−`、`—`、`!`）。保留真实品牌／操作系统 Logo、已确认四路径产品风火轮 Logo、网络类型色线、机柜跳线几何路径及文本含义符号（如数量乘号 `×`）。

1. **通用控件**：新增与下拉统一 `#down`/`#up`、删除与关闭统一 `#close`、新增统一 `#plus`、窗口示意按钮统一 `#minus`/`#square`/`#close`。
2. **业务细节**：机柜锚定状态统一 `#pin`、网络地址池异常统一 `#triangle-alert`、快速生成分段统一 `#zap`、工单流转统一 `#arrow-right`（保留底层 Anime.js 流光路径）、硬件配置折叠统一 `#chevron`。
3. **原生与离线**：原型通过 `vendor/netcatty-icons.js` 统一由 SVG `<use>` 渲染；GPUI 桌面通过 `cmdb-desktop/src/icons.rs` 嵌入离线官方 SVG，不引入外部网络请求或网页宿主。

## 打开原型

在本地浏览器打开 [设备资产原型](device-assets-preview.html#terminal)，即可通过左侧导航访问其他页面；右上角宿主设置图标可打开 **设置 → Cmdb**。也可[直接打开 Cmdb 设置](device-assets-preview.html?settings=cmdb#terminal)。无需安装依赖、构建或启动后端；请保持本目录的相对结构完整。代码托管平台可能只显示 HTML 源码，需下载后在浏览器打开。

新增的联动工作台外壳已撤除；独立原型继续作为业务设计参考。项目主线为 Rust + GPUI，旧 Go／Netcatty 实现已废除；现有原生窗口仅完成部分技术验证，不能据此认定原型设计或业务迁移完成。

机柜设备主体统一放在设备列，中间柜不再跨过U位标尺；左右端口条各限制在设备宽度28%以内，长端口保留完整悬停提示。1U保持24px单行并隐藏型号副行，2U及以上保留副行，端口点击与连线数据不变。本轮浏览器验证中间柜2U为48px，临时1U显示样例为24px、两端端口均在设备边界内，720px无整页横向溢出。

独立桌面产品评审入口为 [资产全景独立预览](standalone-preview.html)，同源地址 `http://127.0.0.1:8765/standalone-preview.html`。顶部窗口栏合入当前页标题和完整原业务工具组，原控件仍在 iframe 文档，桌面一行、窄屏换行。52px 纯图标轨依次为设备资产、组织架构、机柜、网络、工单与统计，底部设置；五个业务页的窗口标题分别为 Device Assets、Organization、Racks、Network、Work Orders & Statistics，设置标题仍为中文。机柜与网络各自直达，独立模式隐藏顶部重复的二级导航，标题、高亮和悬停提示同步。左上角标志约 22px，按用户确认的风火轮效果以3秒一圈匀速旋转；减少动态偏好下静止。原业务 HTML 直接打开仍保留宿主二级导航。

## 本轮设计约定

- 本轮六项界面修正已同步正式源码与原型：①资产/人员侧栏“放大/还原”只切换全宽，“左右分栏”（`columns-2`）独立切换正文单/双列，二者互不共用状态，保留 420px 默认与拖宽；②CPU、内存、磁盘编辑区顶部提供可应用、存为常用、删除的“常用”预设（仅本机），420px 窄栏下按字段宽度折行，无法拆分的原文不被预设覆盖；③三类资产首列表头用不截断短名（“名称 / 编码 / SN”“名称 / 编码”“系统名称”），悬停显示完整名称；④三类资产行操作统一为一个紧凑“操作 ▾”分组菜单，保留查看、编辑、克隆、调换、维修、注销全部适用操作；⑤设置 Cmdb 标题旁为版本标签（正式客户端显示真实发布 tag，未打 tag 显示“开发构建”，原型显示“版本未读取”）与“检查更新”，原型不联网、不编造版本；⑥网络类型目录左侧显示已保存颜色圆点，原型可保存到本页内存并同步列表选择框左侧网络竖线，刷新恢复示例。

- 原业务 HTML 的宿主布局保留“机柜与网络”一级 Router 图标和机柜 Server／网络 Network 二级导航；独立入口改用左轨两个独立图标，并隐藏顶部重复入口。两种宿主复用相同业务 HTML。
- 设备资产三类页面、人员、地址池和工单均只使用一个 `ArrowDownUp` 导入/导出图标，点击后显示菜单；菜单内使用 `Upload` / `Download` 图标。没有数据交换操作的机柜视图不增加虚构导入导出功能。
- 终端、基础设施、业务系统、组织、工单和地址池的顶部新增入口统一使用现有 `primary` 主按钮样式；组织维护的新增节点、IPAM 补录 IP、机柜管理的新建机房/机柜及空 U 位新增设备同样复用该样式。仅显式新增主按钮采用主色，菜单内项目、查询、编辑及原表单行为保留。
- 查询、编辑、关闭、详情页签、导航等共享 [Netcatty 同版本 Lucide 图标数据](vendor/netcatty-icons.js)，不是手绘近似路径。
- 基础设施品牌/型号前显示对应品牌 Logo；终端操作系统前显示 UOS、麒麟、Windows 等实际 Logo。未知、不适用或未配置不冒充已识别品牌；文字仍保留一次。
- 台式机、笔记本的“硬件信息”包含品牌/厂商、型号、CPU、内存（MB）和磁盘；打印机同样显示品牌与型号，复用列表、详情、新增和编辑字段，但不显示 CPU、内存或磁盘。示例打印机填充奔图 PANTUM P2500、联想 LJ2205；品牌可选奔图、立思辰、联想、得力、映美等，也可自定义，候选合并既有型号目录和资产品牌。缺少真实 Logo 的品牌只显示文字，不伪造标志；品牌与型号示例不代表信创认证。
- 三类资产列表及网络详情在已填写 IP 后只显示一个 22px 原生终端小图标，不显示 Netcatty 文字；悬停提示和无障碍名称保留 Netcatty 与目标 IP。终端设备 IP、云桌面业务/物理 IP、基础设施管理/业务 IP、业务系统自身业务 IP 均分别提供入口，基础设施列表在同一地址单元格中区分管理与业务两行，无 IP 不显示图标；长地址在列表截断并保留完整悬停值。离线原型点击只在地址旁提示“请在 Netcatty 客户端中打开该地址的连接”，不新建弹窗、不模拟终端、不显示虚构服务器状态，也不猜测外部唤起协议。
- 业务系统列表在业务IP之前单独显示“访问地址”，直接读取已有access_url，保留完整协议、端口、路径及查询参数；长值换行、可选择文本，不以IP拼造，不创建真实访问链接。有效 http/https 地址旁新增 Netcatty 浏览器小图标（globe），点击提示需在 Netcatty 客户端打开该访问地址（须已关联主机），不弹出模拟浏览器或虚构页面；未配置独立显示，原业务IP不删除。
- 本条资产面板三按钮与单双列约定对直接业务 HTML 及基础设施/业务系统保留；独立入口终端详情仅将停靠方向改为底部，高度拖拽与全宽展开独立于正文单双列。
- 工单概览保持单排：新建 → 处理中 → 已解决 → 已关闭；已取消是同排独立的弱化状态，不接在“已关闭”之后的成功路线上。阶段数量和点击筛选保留，主列表获得更多高度。
- 人员详情统一420px右栏，人员资料、组织归属、名下资产、资产交接四个图标页签（名称在悬停提示中，与原生一致）；人员编辑同样只显示“人员资料／组织归属”两个图标页签。编辑采用同一右栏、新增采用860px居中表单，人员资料与组织归属分区共享输入。八个原有字段、备注、接收人选择保留，切换分区及展开还原不丢草稿；删除收进更多菜单，真实保存、删除和交接仍禁用。
- 工单详情改为紧凑 720px 居中单列，去掉大流程图、重播和暂停。主题、状态、基本信息和关联资料直接展示；处理结果、时间线及添加记录收进默认折叠的“处理记录”。保留下一步和取消操作，结单仍逐张要求处理结果；列表单排概览及动画不变。
- 所有当前业务页面均可从右上角设置图标进入同一个 Cmdb 设置原型。排版对照 Netcatty 的 `SettingsPage`、`SettingCard`、`SettingRow` 和 `Tabs`：保留宿主设置导航，Cmdb 内容改为固定页头与五个分区页签——资产目录、工单配置、导入模板、项目存储、同步维护。八个原有配置区完整保留，每次只展示当前页签；14px 设置名称、12px 说明、36px 输入控件，说明过长时可悬停查看全文，不再纵向堆成长页面。
- Cmdb 设置搜索覆盖全部分区，选择结果自动切换对应页签并定位；支持匹配结果、方向键/回车和空结果，Esc 只收起搜索。页签支持方向键、Home/End；切换保留项目输入、开关状态和各区滚动位置。项目名称、项目编码、附件目录/容量和同步结果均不伪造；目录为明确的结构样例，不能当作实际项目配置。
- 云同步只保留一个“同步 Cmdb 数据”总开关，设计范围明确包含资产、组织及联系电话、IP、工单和履历；移除电话/履历分项开关、同步状态行和“立即同步”按钮，云同步的执行与状态由宿主统一管理。“同步历史台账”改为“旧台账迁入”，提供“查看迁入预览”，保留当前项目范围、已有映射跳过和原数据保护约定。这是原型设计调整，正式同步行为未改动。
- 三类资产列表与原生一致：网络类型标记从名称后的 8px 色点改为紧邻选择框左侧、约 2px 宽的整行竖线，不改变列宽或遮挡选择框；颜色读取“设置 → Cmdb → 网络与型号 → 网络类型”（示例：专网 `#2563EB`、外网 `#F59E0B`、内网 `#10B981`），未配置或目录未设色时使用中性灰。竖线保留 `title` 与无障碍网络类型说明，细线上的流光仅使用 CSS `transform`/`opacity`，减少动态时静态显示；独立网络类型文字列继续保留。首列表头与原生一致为不截断短名并悬停显示完整名称：终端“名称 / 编码 / SN”（设备名称 / 资产编号 / 设备SN）、基础设施“名称 / 编码”（设备名称 / 资产编号）、业务系统“系统名称”。网络类型目录提供颜色选择器和 `#RRGGBB` 输入，左侧目录显示已保存颜色圆点，与原生 `ConfigCenter` / `SettingsCatalogEditor` 一致。
